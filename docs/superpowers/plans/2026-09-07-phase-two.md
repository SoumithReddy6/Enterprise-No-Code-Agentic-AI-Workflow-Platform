# Phase Two Implementation Plan

**Goal:** Add Ollama, authenticated workspaces and durable node-result recovery.
**Spec:** ../specs/2026-09-07-phase-two-design.md
**Execution:** Subagent-driven development for the isolated auth module; main agent owns storage, worker and Ollama integration.

- [x] Provider: tests for native Ollama protocol/errors; add backend model discovery and frontend model selector.
- [x] Storage: additive schema migration for tenant ownership; tenant-scoped methods; transactional fenced job claims, heartbeat, cancellation and checkpoints.
- [x] Auth: isolated auth tables/routes and session dependency; frontend authentication gate; bootstrap claims existing local data transactionally.
- [x] Worker: actual LangGraph execution with persisted completed results; heartbeat and recovery; launch separately from API; resume action.
- [x] Integration: protect API and proxy cookies; preserve save/import behavior; check tests, live Ollama, PostgreSQL and built frontend.
- [x] Review: independent review and fixes, then documentation and final verification.

Ruling: retain SQLite as the default and use the SQL database as the durable queue. This makes the next phase usable locally without mandatory Redis and preserves existing data. Native LangGraph checkpoint serialization and external identity providers are later milestones.
